# 08 - Termo de Parceria / Cooperação

Inserir aqui a documentação formal da parceria com a instituição/comunidade beneficiada.

Documentos esperados:
- Termo de Cooperação assinado
- Carta de Interesse / Anuência
- Protocolo de Colaboração
- Autorização para uso de imagem (quando houver fotos/vídeos)
- Comprovação do registro no Sistema de Extensão Institucional da PUC Minas

> ⚠️ Documentos com assinaturas digitalizadas devem ter dados sensíveis (CPF, RG) tarjados antes de comitar no repositório público.
