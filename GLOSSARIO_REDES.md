# Glossário de Redes de Computadores

Termos técnicos utilizados ao longo dos projetos do CST em Redes de Computadores. Use este arquivo como referência rápida e contribua adicionando novos verbetes encontrados durante os projetos.

## A
- **ACL (Access Control List):** lista de regras que permite ou nega tráfego com base em critérios (IP de origem/destino, porta, protocolo).
- **ARP (Address Resolution Protocol):** protocolo que mapeia endereços IPv4 para endereços MAC em uma rede local.
- **AP (Access Point):** equipamento que provê conectividade Wi-Fi à rede cabeada.

## B
- **BGP (Border Gateway Protocol):** protocolo de roteamento usado entre sistemas autônomos na Internet.
- **Bridge:** dispositivo que conecta dois segmentos de rede na camada de enlace.

## C
- **CIDR (Classless Inter-Domain Routing):** notação que substituiu o esquema de classes do IPv4, permitindo prefixos arbitrários.
- **CSMA/CD e CSMA/CA:** métodos de acesso ao meio em Ethernet (CD) e Wi-Fi (CA).

## D
- **DHCP (Dynamic Host Configuration Protocol):** atribui dinamicamente IP, máscara, gateway e DNS aos hosts.
- **DMZ (Demilitarized Zone):** segmento de rede que isola servidores expostos à Internet do restante da rede interna.
- **DNS (Domain Name System):** resolve nomes de domínio para endereços IP.

## E
- **EIGRP (Enhanced Interior Gateway Routing Protocol):** protocolo proprietário Cisco para roteamento interno.

## F
- **FCAPS:** modelo de gerência de redes da ISO — Falhas, Configuração, Contabilidade (Accounting), Desempenho (Performance) e Segurança.
- **Firewall:** equipamento ou software que filtra tráfego com base em regras de segurança.

## G
- **Gateway:** dispositivo que conecta redes distintas, geralmente um roteador.

## H
- **Hardening:** processo de reduzir a superfície de ataque de um sistema por meio de configurações restritivas.

## I
- **IDS / IPS (Intrusion Detection / Prevention System):** detecta (IDS) ou bloqueia (IPS) atividades suspeitas na rede.
- **IPSec:** conjunto de protocolos para autenticação e criptografia na camada IP, base para muitas VPNs.

## L
- **LGPD:** Lei Geral de Proteção de Dados (Lei 13.709/2018).
- **LAN / MAN / WAN:** Local / Metropolitan / Wide Area Network.

## M
- **MAC Address:** endereço físico de uma interface de rede (48 bits).
- **MIB (Management Information Base):** base de objetos gerenciáveis usada pelo SNMP.

## N
- **NAT (Network Address Translation):** tradução de endereços, comumente usado para conectar IPs privados à Internet.
- **NetFlow / sFlow:** protocolos para coleta de estatísticas de tráfego.

## O
- **OSI:** modelo de referência de 7 camadas (Física, Enlace, Rede, Transporte, Sessão, Apresentação, Aplicação).
- **OSPF (Open Shortest Path First):** protocolo de roteamento por estado de enlace para redes IP.

## P
- **PoE (Power over Ethernet):** entrega de energia elétrica pelo cabo Ethernet (802.3af/at/bt).
- **Port Security:** funcionalidade de switches Cisco que limita os MACs permitidos por porta.

## Q
- **QoS (Quality of Service):** mecanismos para priorizar tráfegos sensíveis (voz, vídeo).

## R
- **RADIUS / TACACS+:** protocolos de AAA (Authentication, Authorization, Accounting).
- **RIP:** protocolo de roteamento por vetor de distância, hoje considerado legado.

## S
- **Site Survey:** levantamento técnico de um ambiente para projeto de Wi-Fi.
- **SNMP (Simple Network Management Protocol):** protocolo para coleta e gerência de dispositivos de rede.
- **SLA (Service Level Agreement):** acordo de nível de serviço.
- **STP (Spanning Tree Protocol):** evita loops de camada 2 em redes comutadas.

## T
- **TCP / UDP:** protocolos de transporte — orientado a conexão (TCP) e sem conexão (UDP).
- **TLS:** Transport Layer Security — criptografia da camada de transporte (HTTPS, etc.).
- **Trunk (802.1Q):** porta que transporta tráfego de múltiplas VLANs com tagging.

## V
- **VLAN (Virtual LAN):** segmentação lógica de uma rede comutada.
- **VLSM (Variable Length Subnet Masking):** máscaras de sub-rede de tamanhos diferentes em uma mesma rede.
- **VPN (Virtual Private Network):** rede privada sobre uma rede pública.

## W
- **WPA2 / WPA3:** padrões de segurança Wi-Fi.

## Z
- **Zero Trust:** modelo de segurança em que nenhum tráfego é confiável por padrão, mesmo dentro do perímetro.
