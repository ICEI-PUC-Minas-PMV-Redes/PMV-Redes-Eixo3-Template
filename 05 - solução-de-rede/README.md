# 06 - Solução de Rede

Inserir aqui o projeto técnico da solução de rede proposta à comunidade.

Artefatos esperados:
- Projeto lógico (topologia, endereçamento, VLANs)
- Projeto físico (planta com pontos de rede, AP, switches)
- BOM (Bill of Materials) com cotação dos equipamentos
- Justificativa técnica das escolhas (modelo de roteador, antenas, padrões 802.11)
- Configurações exportadas dos equipamentos instalados
- Manual de operação básico para a comunidade
