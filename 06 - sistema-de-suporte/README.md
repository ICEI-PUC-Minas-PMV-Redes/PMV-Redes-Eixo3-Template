# 07 - Sistema de Suporte

*(Esta pasta só é usada quando o projeto extensionista envolver, além da rede, o desenvolvimento de um sistema de software de apoio)*

Exemplos de sistemas de suporte típicos:
- Portal cativo (captive portal) com cadastro de usuários
- Painel web para a comunidade gerenciar o Wi-Fi
- App de orientação ao usuário final (FAQ, suporte)
- Sistema de chamados / suporte técnico para reportar problemas

Artefatos esperados:
- Código-fonte (ou link para o repositório dedicado)
- Documentação de instalação
- Diagrama da arquitetura
- Manual do usuário

> Se o sistema de suporte tiver repositório próprio no GitHub/GitLab, basta linkar aqui.
