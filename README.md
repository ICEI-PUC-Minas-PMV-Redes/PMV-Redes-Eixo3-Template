# Projeto Extensionista — Eixo 3
**PUC Minas — CST em Redes de Computadores**

Template de repositório para os projetos do Eixo 3: **Redes para a Comunidade**.

Cada grupo copia este repositório, preenche a ficha do projeto e deposita os artefatos nas pastas
correspondentes. **Preencha apenas o que for relevante ao seu projeto** — campo que não se aplica
pode ser removido.

---

## Por onde começar

1. Preencha a **[Ficha do Projeto](01%20-%20identifica%C3%A7%C3%A3o/ficha-projeto.md)** — é o documento principal e o resumo de tudo.
2. Deposite os artefatos nas pastas numeradas (cada pasta tem um `README.md` explicando o que colocar).
3. Atualize a ficha ao longo do semestre, não só na entrega final.

## Estrutura do repositório

| Pasta | O que colocar | |
|---|---|---|
| `01 - identificação` | Ficha do projeto, proposta inicial, apresentação final | Obrigatório |
| `02 - diagnóstico-comunidade` | Levantamento da demanda e da situação encontrada | Obrigatório |
| `03 - solução-de-rede` | Projeto lógico e físico, configurações, manual de operação | Obrigatório |
| `04 - sistema-de-suporte` | Software de apoio (portal cativo, painel, app) | Só se houver |
| `05 - termo-parceria` | Termo de cooperação e autorizações de imagem | Só se houver |

## Checklist de entrega

- [ ] Ficha do projeto preenchida
- [ ] Diagnóstico da comunidade com evidências (fotos, medições, entrevistas)
- [ ] Topologia e endereçamento documentados
- [ ] Configurações finais dos equipamentos exportadas
- [ ] Manual de operação entregue à comunidade
- [ ] Resultados medidos (antes → depois)
- [ ] Termo de parceria e autorizações de imagem, quando houver

## Privacidade — leia antes de comitar

Este repositório é público. Antes de subir qualquer arquivo:

- Tarje CPF, RG e endereços em documentos digitalizados.
- Borre rostos e placas em fotos sem autorização de uso de imagem.
- **Nunca** comite senhas, chaves Wi-Fi ou credenciais de equipamentos — substitua por `<removido>`
  nas configurações exportadas.
