# 05 — Termo de Parceria *(quando aplicável)*

Documentação formal da parceria com a instituição ou comunidade beneficiada.

**O essencial:**
- Termo de cooperação assinado, carta de anuência ou de interesse
- Autorização de uso de imagem, se o projeto tem fotos ou vídeos de pessoas
- Comprovante de registro no Sistema de Extensão da PUC Minas

> ⚠️ Tarje CPF, RG e endereços antes de comitar documentos assinados.
