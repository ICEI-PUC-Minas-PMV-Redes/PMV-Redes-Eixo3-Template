# 03 — Solução de Rede

O projeto técnico entregue à comunidade.

**O essencial:**
- Projeto lógico: topologia, endereçamento, VLANs
- Projeto físico: planta com pontos de rede, APs e switches
- Justificativa das escolhas técnicas (equipamentos, padrões, cabeamento)
- Configurações finais dos equipamentos
- Manual de operação básico, em linguagem acessível à comunidade

**Se houver:**
- Lista de materiais (BOM) com cotação
- Simulações (Packet Tracer, GNS3) e testes realizados

> ⚠️ Remova senhas e chaves Wi-Fi das configurações antes de comitar.
