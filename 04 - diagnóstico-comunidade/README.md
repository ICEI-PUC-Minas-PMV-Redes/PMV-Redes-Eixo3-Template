# 05 - Diagnóstico da Comunidade

Inserir aqui o levantamento da demanda e a caracterização da comunidade beneficiada.

Artefatos esperados:
- Relatório de visita técnica inicial
- Entrevistas / questionários aplicados (com termo de consentimento)
- Site survey (cobertura Wi-Fi atual, ruído, interferências)
- Fotos do local (com autorização para divulgação)

- Perfil socioeconômico do público atendido
